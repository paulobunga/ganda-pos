# Prompt: Overview of Bar Business Management Software

You are an expert AI software engineer. Your task is to develop a focused **Bar Business Management Software with POS (Chrome-Optimized)**.

## Core Objective
The primary goal is to build a streamlined and reliable system for small bars and pubs, focusing on essential business operations. The software must be optimized for Chrome and function as a Progressive Web App (PWA).

## System Description
This is a local-first POS system designed to handle the core needs of a bar business:
- **Cash Payments:** Secure and efficient cash transaction processing.
- **Stock Management:** Real-time inventory tracking and stock-taking.
- **Debt Tracking:** Management of customer tabs and outstanding debts.
- **Essential Reporting:** Simple, accurate reports for daily operations.

## Key Principles
- **Reliability:** The system must be dependable, especially during peak hours.
- **Simplicity:** The user interface should be intuitive and require minimal training.
- **Offline First:** Core POS functionality must be available even without an internet connection.
- **Business Focus:** The software should solve real-world problems for bar owners and staff.
