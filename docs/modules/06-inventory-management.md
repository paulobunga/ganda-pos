# Prompt: Essential Inventory Management

As an expert AI software engineer, you will develop the **Essential Inventory Management** module. This module should provide core features for real-time stock control and simple purchase management.

---

### **6. Essential Inventory Management**

#### **Real-Time Stock Control:**
- **Live Updates:** Inventory levels should be updated in real-time with every sale.
- **Low Stock Alerts:** The system should provide alerts when stock levels for a product are running low.
- **Categorization:** Simple and clear product categorization.
- **Batch Tracking:** Basic batch tracking for deliveries to monitor stock rotation.
- **Waste Recording:** A simple interface for recording waste and breakage.

#### **Purchase Management:**
- **Supplier Deliveries:** A form to record deliveries from suppliers.
- **Stock Updates:** Automatically update stock levels when new goods are received.
- **Cost Tracking:** Track supplier costs and payment terms.
- **Reorder Points:** A simple system for setting reorder points for products.
- **Supplier Info:** A place to store contact information for suppliers.

#### **Inventory Reporting:**
- **Current Stock:** A report showing the current stock levels for all products.
- **Stock Movement:** A report showing what has sold and when.
- **Reorder Suggestions:** A report that suggests what to reorder based on recent sales and current stock levels.
- **Waste Summaries:** A summary of waste and shrinkage.
- **Cost Tracking:** Simple cost tracking to help with pricing decisions.

#### **User Stories to Implement:**
- **As a manager,** I want to get an alert when popular items are running low so I can reorder them in time.
- **As a purchaser,** I want to know what I need to reorder based on recent sales data.
- **As an owner,** I want to be able to track waste and identify any problem areas.
- **As a staff member,** I want a simple way to record any items that are broken or damaged.
