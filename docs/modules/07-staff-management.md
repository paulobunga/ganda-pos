# Prompt: Staff Management & Access Control

As an expert AI software engineer, you will develop the **Staff Management & Access Control** module. This module will provide basic user management and security features.

---

### **7. Staff Management & Access Control**

#### **Basic User Management:**
- **Role System:** A simple role system with predefined roles (e.g., Manager, Bartender, Cashier).
- **PIN Login:** A PIN-based login system for quick access to the POS.
- **Activity Logging:** Basic activity logging to ensure accountability.
- **Shift Assignment:** The ability to assign staff to specific shifts.
- **Performance Metrics:** Simple performance metrics, such as sales per shift.

#### **Access Control:**
- **Role-Based Access:** Feature access should be based on the user's role (e.g., only managers can process refunds).
- **Transaction Logging:** All transactions should be logged with the staff member's ID.
- **Cash Handling Permissions:** Permissions for cash handling operations, such as opening/closing the register.
- **Report Access:** Access to reports should be based on job function.
- **Security:** The system should have basic security measures, such as automatic session timeouts.

#### **User Stories to Implement:**
- **As an owner,** I want to know which staff member processed each transaction for accountability.
- **As a manager,** I want to be able to assign different levels of access to different staff members.
- **As a staff member,** I want a quick way to log in during a busy shift without needing a complex password.
- **As an owner,** I want basic activity logs that allow me to track staff performance and identify any issues.
