# Prompt: Technical Implementation

As an expert AI software engineer, you are to build the **Bar Business Management Software** using the following technical stack and security principles.

---

## **Technical Implementation**

### **Frontend Framework**
- **SvelteKit** for a fast, responsive interface.
- **TypeScript** for reliable and type-safe code.
- **Tailwind CSS** for a clean, touch-friendly design.
- **Progressive Web App (PWA)** with full offline capabilities.

### **Data Storage**
- **IndexedDB** for robust local data storage.
- **Background Sync** for reliable data synchronization when the network is available.
- **Service Worker** to manage offline functionality and caching.
- **Simple backup mechanism** to prevent data loss.

### **Security**
- **Basic data encryption** for sensitive information stored locally.
- **Simple user authentication** with PINs for quick access.
- **Activity logging** for audit trails and accountability.
- **Secure cash handling procedures** enforced by the software.

Your architecture should be modular and scalable to accommodate future enhancements.
