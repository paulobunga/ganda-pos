# Prompt 1: Core POS Module

Build the **POS module** for the Bar Business System.

## Requirements:
- Fast, responsive POS screen optimized for touch.
- Features:
  - Product search and selection.
  - Multiple open tabs for different customers.
  - Split bills and partial payments.
  - Apply promotions automatically.
- Store transactions in IndexedDB with UUIDs.
- Update stock levels locally when sales occur.
- Include a sync queue for offline-first operation.
- Unit tests for adding, updating, and closing tabs.

## Deliverables:
- POS UI and logic.
- IndexedDB integration.
- Sample test data.
