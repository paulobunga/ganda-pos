# Prompt 9: Testing & QA Automation

Set up automated testing for the Bar POS system.

## Requirements:
- Unit tests for each module (POS, Inventory, Tabs, Reporting, etc.).
- Integration tests for offline/online workflows.
- Sync conflict resolution tests.
- Manual QA scripts for shift reconciliation and Z-out flows.

## Deliverables:
- Test coverage report.
- Scripts for running tests.
- Sample QA checklist for manual testing.
