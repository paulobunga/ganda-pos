# Prompt 6: Reporting & Z-Out Module

Build the **Reporting and Z-Out module**.

## Requirements:
- Daily, weekly, and monthly reports:
  - Sales totals, cash vs. card, outstanding tabs, inventory usage.
- Z-out reporting:
  - Shift start cash.
  - Shift sales.
  - Variance detection.
  - Printable PDF report.
- CSV and PDF export using File System Access API.
- Offline generation with queued sync for daily backups.

## Deliverables:
- Reports dashboard.
- Z-out workflow with end-of-shift reconciliation.
- Export buttons for CSV and PDF.
- Unit tests for report accuracy.
