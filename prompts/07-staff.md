# Prompt 7: Staff & Access Control Module

Create the **Staff and Access Control module**.

## Requirements:
- Role-based access: Admin, Manager, Cashier, Bartender.
- PIN or QR code login for quick switching.
- Activity logging:
  - Who created transactions.
  - Time stamps for accountability.
- Offline-first login system with sync on reconnect.

## Deliverables:
- Staff CRUD interface.
- Login/logout workflow.
- Role-based route protection.
- Unit tests for permissions and access.
