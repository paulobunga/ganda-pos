# Usage Guide for AI

1. Start with **Prompt 0 (Setup)** to scaffold the project.
2. Implement each module **sequentially**:

   * POS → Inventory → Customers → Purchases → Sales → Reporting → Staff → Sync.
3. Test after each module to ensure no regressions.
4. Use prompts iteratively:

   * “Refactor this module to improve X”
   * “Integrate this module with Y”
   * “Optimize this feature for performance.”
5. After all modules are stable, proceed to **testing, deployment, and enhancements**.
